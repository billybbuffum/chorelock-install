Install ChoreLock
  1. Open this page in Safari on the iPhone (other browsers can't install apps).
  2. Tap Install ChoreLock, then Install on the prompt. The icon appears on the home screen and fills in as it downloads.
  3. First time only: turn on Developer Mode under Settings > Privacy & Security (the phone restarts), then trust the developer under Settings > General > VPN & Device Management.

Only works on phones registered with the developer account. Later builds install over the earlier one and keep your chores. Builds come from GitHub Actions.
